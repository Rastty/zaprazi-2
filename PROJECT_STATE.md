## Cíl a fáze

Pomáhat lidem řešit praktické problémy bezpečného domova cestou **problém → Domácí poradce → vhodné možnosti → koupit / půjčit / ověřit úhradu → konkrétní bezpečná akce**. První obchodní důkaz: **schválená affiliate objednávka** přiřaditelná k relevantní návštěvě. P0 zůstává Mobility; web není obecný katalog ani medicínské doporučení.

## Blokace a další priorita podle efektu / pracnosti

1. **P0 — schválená affiliate objednávka a publisher atribuce ([issue #857](https://github.com/Rastty/zaprazi-2/issues/857)):** Největší obchodní efekt. Vloženo je 25/25 odpovídajících cílů, ale partner-side redirect, vlastnictví CJ property `zaprazi.cz`, pending/rejected/**approved** provize a skutečný obchod zůstávají **UNKNOWN**. Na produkci je 21/21 CJ linků se shodným website ID, což **neprokazuje jeho vlastnictví**. Prometheus Core již má `publisherCommissions` adapter; nepřidávat duplicitní reader, nepoužívat advertiser provize a nevytvářet testovací merchant kliky. **Přesná potřebná externí akce:** vlastník v CJ *publisher* účtu potvrdí aktuální web/property a zpřístupní nebo poskytne anonymní report schválených provizí pro tuto property.
2. **P0 — doložit dodávanou variantu MEYRA:** Rozpor výrobce 61,5 cm vs. retailer 59 cm musí zůstat viditelný a nabídka za fit-gate. Retail `offers[].checkedAt=2026-10-06` je starý; aktualizace pouze po nové přesné merchant evidenci, ne kosmetickým přepsáním data. BESCO WA17/WA21 již byly ověřeny 19. 11. a znovu se neprověřují. Samotná dokumentace nevyžaduje další WordPress release.
3. **P1 — homepage indexace:** Majitel 20. 11. již požádal o indexaci `/`, neopakovat. Poslední [GSC snapshot](docs/SEO_INDEXATION_TRIAGE_2026_11_20.md) uvádí `crawled_not_indexed`; živá technická QA nyní PASS, ale čeká se na reálnou změnu v GSC. Cíleně zkontrolovat také `/sprchovaci-zidle-pro-seniory/` a dva `inspection_unavailable` Mobility slugs při další inspekci.
4. **P1 — jediný doložený SEO/UX zásah:** Stávající `/choditko-na-pojistovnu/` má 50 impresí / 1 klik za 28 dní do 17. 11., ale chybí bezpečně přiřaditelný page/query intent. Vylepšit jen při novém důkazu potřeb uživatelů a bez kanibalizace; nepřepisovat články naslepo.

**Provozní hranice:** lokální odpovědi poradce se nesmějí posílat do analytiky ani affiliate parametrů; vhodnost řešení nikdy neřadit podle provize. Rutinní změny přes dedikovanou větev → CI → PR → bezpečný merge; runtime až po odděleném WordPress Pull + Deploy a postdeploy readbacku.
