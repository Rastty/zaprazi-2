## Legacy embedded-document sanitation

Authenticated read-only counts across 4,360 published posts found:
- 3,994 posts containing an embedded `<!DOCTYPE html>`,
- 4,030 containing an `<html>` tag,
- 4,079 containing a `<head>` tag,
- 4,037 containing a `<body>` tag.

This is widespread imported legacy markup, not an isolated article defect.

RC behavior is non-destructive and render-only for singular legacy `post` pages:
- removes embedded DOCTYPE,
- removes the nested `<head>...</head>` block,
- strips only opening/closing `<html>` and `<body>` wrappers,
- preserves article text, images and body content,
- does not modify database content, pages, products or the new homepage.


## Consent-aware analytics boundary

The Advisor no longer calls a global `gtag` function even if one happens to exist.

RC behavior:
- emits only local `zaprazi:analytics` CustomEvents,
- event payload contains only the generic event name,
- no questionnaire answer, product ID, merchant ID or derived profile is attached,
- GA4 forwarding remains disabled until a separate consent-aware adapter is intentionally installed.

This prevents a future plugin or tag injection from silently turning Advisor events into external analytics before consent handling is defined.


## Accessible Advisor validation

Because the Advisor intentionally avoids native form submission for privacy, browser-native required-field blocking is not relied upon.

RC behavior:
- validates all visible required question groups before running the engine,
- always requires environment + support need,
- requires walker-lift choice only on the indoor branch,
- requires brake-use choice only on outdoor/both branches,
- accepts explicit "Nevím" as a valid conscious answer,
- highlights missing groups,
- announces a concise error through an assertive live region,
- moves keyboard focus to the first missing question,
- clears stale error state when a conditional branch becomes hidden.


## Global keyboard navigation

RC now provides a visible-on-focus **Přeskočit na hlavní obsah** link immediately after `wp_body_open()`.

The target exists consistently on:
- homepage,
- singular legacy posts,
- legacy pages,
- index/archive pages,
- WooCommerce shop/product rendering.

The target is programmatically focusable without adding an unnecessary visible focus outline after the skip action.


## Evidence freshness guard

RC now distinguishes stable technical evidence from time-sensitive commercial/reimbursement evidence.

Current windows:
- product technical/manual evidence: 365 days,
- merchant offer evidence: 30 days,
- rental price/availability evidence: 30 days,
- reimbursement evidence: maximum 31 days **and** never beyond the explicit monthly `validThrough` date.

After expiry:
- technical sources remain visible but are marked for re-verification,
- merchant links remain available but carry a stale-evidence warning,
- exact rental prices are no longer displayed as current,
- expired monthly reimbursement amounts are hidden and replaced with a neutral instruction to verify the new SÚKL list.

Freshness is calculated from the explicit `checkedAt` date and does not alter recommendation ranking.


## System-page fallbacks

RC now has dedicated templates for:
- 404/not-found pages,
- WordPress search results.

This prevents those routes from falling into the generic legacy archive template and showing the misleading heading "Starší články". Both templates retain the global skip-link target and offer a route back to the new homepage/Advisor.


## Legacy generated-document tails

Follow-up authenticated analysis found generated page chrome inside legacy post bodies:
- 1,777 posts contain `<header>`,
- 406 contain `<nav>`,
- 361 contain placeholder hash links such as `href="#"`,
- 1,524 contain `<footer>`.

Representative full-document samples contained fake internal navigation (Domů / O nás / Kontakt), example.com links and generated copyright footers.

Across all 3,994 posts containing `<!DOCTYPE html>`:
- none had the first DOCTYPE in the first 100 characters,
- 659 first appeared between characters 101–500,
- 3,335 first appeared after character 500,
- average first position was ~1,499 characters,
- earliest observed first position was 192.

RC 0.8.0 therefore prefers the original content prefix when a later DOCTYPE is followed by a real `html/head/body` document signature and the prefix contains meaningful text. Everything from that generated document onward is suppressed at render time only.

Fallback wrapper sanitation remains for malformed legacy records without the full signature. Stored WordPress content is not modified.
