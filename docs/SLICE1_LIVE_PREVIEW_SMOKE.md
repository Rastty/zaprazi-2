# Slice 1 Mobility — Live Preview / Activation Smoke

Use this checklist before activating ZaPrazi 2.0 RC as the production theme.

## A. Safe preview entry

Preferred first step:
**WordPress → Vzhled → Šablony → ZaPrazi 2.0 RC → Živý náhled**

Do not activate immediately.

Expected rollback:
- current production theme remains Flatsome,
- if preview is wrong, simply close the preview,
- no legacy redirects or content deletions are part of this release.

## B. Homepage / mobile

Check at desktop and narrow/mobile width:

- hero title fits without horizontal scrolling,
- primary CTA scrolls to Domácí poradce,
- "Nejdřív si přečíst" scrolls to selection guidance,
- form cards remain readable and touch targets are comfortably large,
- decision, acquisition, methodology and FAQ sections remain readable,
- footer disclosure is visible.

## C. Advisor branches

### Indoor / can lift
Answers:
- Hlavně doma
- Stabilní oporu
- Zvládne lehce nadzvednout: Ano

Expected:
- fixed/two-wheel walker candidate family,
- BESCO WA17 + WA21 shortlist,
- technical facts,
- source blocks,
- merchant links.

### Indoor / cannot lift
Answers:
- Hlavně doma
- Stabilní oporu
- Zvládne lehce nadzvednout: Ne

Expected:
- two-wheel walker candidate,
- only BESCO WA21 shortlist.

### Outdoor
Answers:
- Hlavně venku
- Stabilní oporu
- Ruční brzdy: Ano

Expected:
- rollator candidate,
- MEYRA Ideal 3061982,
- merchant offers,
- reimbursement verification card,
- rental card except when duration is explicitly long-term.

### Outdoor / brake unknown
Expected:
- no product shortlist,
- clear request to verify brake use.

### Frequent physical assistance
Expected:
- professional-check boundary,
- no product shortlist.

### Light support
Expected:
- outside-current-slice message,
- no forced walker recommendation.

## D. Privacy

Inspect page URL and browser devtools:

- no questionnaire answer appears in the URL,
- no form submission request sends answer values to WordPress,
- no localStorage/sessionStorage/cookie is created by the advisor for answers,
- generic analytics events contain event names only,
- no diagnosis-like or answer-derived parameter is sent.

## E. Merchant / affiliate routing

Without affiliate links configured:
- merchant CTA uses canonical verified merchant URL,
- no "Partnerský odkaz" label is shown.

After an exact VIV deeplink is configured in:
**Nastavení → ZaPrazi affiliate**

Expected:
- only the matching merchant/product CTA switches to the configured affiliate URL,
- link has sponsored/nofollow relationship,
- recommendation/product order remains unchanged.

## F. Trust / sources

Every production-recommended product must show:
- source block,
- source link,
- checked date.

MEYRA reimbursement:
- manufacturer claim must be clearly identified,
- exact current official reimbursement amount must NOT be shown until official monthly SÚKL record is verified,
- official SÚKL verification link must be present.

## G. SEO basics

Homepage source/head:
- one useful title,
- useful meta description,
- canonical remains homepage,
- no accidental noindex,
- H1 is unique,
- advisor/results do not create crawlable parameter URLs.

After activation:
- request homepage recrawl in Search Console,
- verify sitemap/canonical generated by Yoast,
- confirm existing GA4 stream before adding any duplicate property.

## H. Legacy rendering

Open at least:
- one existing legacy post,
- one existing page,
- one archive/category URL.

Expected:
- content remains readable,
- no PHP fatal,
- no obvious missing main content,
- legacy URLs are not redirected yet.

## I. Activation gate

Activate the ZaPrazi 2.0 theme only if:
- no fatal/error,
- all critical Advisor branches above pass,
- legacy sample pages remain usable,
- no answer privacy leakage is observed,
- outbound links resolve correctly.

After activation, immediately repeat:
1. homepage desktop,
2. homepage mobile,
3. indoor branch,
4. outdoor branch,
5. one legacy post,
6. merchant outbound click.

If a critical issue appears:
**Vzhled → Šablony → reactivate Flatsome**.
