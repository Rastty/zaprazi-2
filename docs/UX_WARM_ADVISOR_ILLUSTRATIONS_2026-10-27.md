# Zápraží UX – přívětivější hlavní poradci

27. 10. 2026. Vlastní originální SVG (720 × 510, cca 2,5–3 kB každé) pro chodítka, koupelnu a soběstačnost. Zachovávají teplou pastelovou paletu domovské ilustrace a znázorňují tři různé činnosti, nikoli obecný opakovaný obrázek. Součástí obrázků jsou SVG title/desc, český alt a popisek pro čtenáře.

Do prvních obrazovek /choditka-pro-seniory/, /koupelna-a-wc/ a /sobestacnost/ jsou vloženy do existující responzivní grid hero komponenty s mobile fallbackem. Původní obsah a poradenská, affiliate ani bezpečnostní logika se nemění. Nevyužívá externí fotobanku ani žádné trackery. Kresby nejsou technickým návodem k montáži nebo použití.

Testy: jeden H1, původní výběrové odkazy, zdroj vlastního obrázku, fixní rozměry proti layout shiftu, alt, vlastní bezskriptové SVG a mobilní CSS. Jde o UX vylepšení; nelze z něho automaticky odvodit růst návštěvnosti ani konverzí. Další atomický release má mít vlastní marker a živou kontrolu všech tří SVG a jejich vykreslení.
